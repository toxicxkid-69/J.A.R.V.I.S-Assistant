## 1. Time, Date & Clock
Jarvis understands natural time and calendar phrasing.

| Example Voice / Text Command | Jarvis Action |
| :--- | :--- |
| `"What is the time?"` | Announces the current local time with AM/PM. |
| `"Tell me current time"` | Announces the time. |
| `"Time"` | Quick time announcement. |
| `"What is today's date?"` | Announces today's day of the week, date, month, and year. |
| `"What date is it?"` | Announces the current date. |
| `"Tell me the current date and time"` | Announces both the current time and today's date together. |

## 2. YouTube Direct Playback & Subscriptions
Jarvis resolves top video IDs directly to play videos immediately rather than just showing search results.

| Example Voice / Text Command | Jarvis Action |
| :--- | :--- |
| `"Open YouTube and play latest video of CarryMinati"` | Automatically finds and **immediately plays** CarryMinati's latest video. |
| `"Play Shape of You on YouTube"` | Resolves and streams Ed Sheeran's official video on YouTube. |

| `"Play interstellar theme on YouTube on Edge"` | Directly plays the soundtrack in Microsoft Edge. |

| `"Subscrive CarryMinati on YouTube"` | Handles phonetic typos and opens the channel page. |

| `"Open YouTube and search Python tutorials"` | Opens YouTube search results for Python tutorials. |
| `"Search gaming highlights on YouTube"` | Displays YouTube search results for gaming highlights. |
| `"Open YouTube"` | Launches the YouTube homepage. |

## 3. Music & Audio Jukebox
Jarvis checks your local Windows Music directory first; if no local files exist, it automatically streams online.

| Example Voice / Text Command | Jarvis Action |
| :--- | :--- |
| `"Play a music"` | Plays a song from your `Music` folder or streams trending hits on YouTube. |
| `"Play some music"` | Starts music playback. |
| `"Play Arijit Singh music"` | Searches and streams Arijit Singh tracks on YouTube. |
| `"Play Coldplay song"` | Plays Coldplay songs. |
| `"Pause music"` / `"Pause video"` / `"Pause"` | Toggles play/pause for currently playing media. |
| `"Next song"` / `"Next track"` / `"Skip song"` | Skips to the next audio/video track. |
| `"Previous song"` / `"Prev track"` | Returns to the previous track. |

## 4. Notes & Memory Management
Jarvis maintains a persistent memory log stored with timestamps in `Jarvis/data.txt`.

| Example Voice / Text Command | Jarvis Action |
| :--- | :--- |
| `"Add note submit final project by Friday"` | Records timestamped note: `[YYYY-MM-DD] submit final project by Friday`. |
| `"Remember that I have a dentist appointment at 4 PM"` | Saves appointment note to memory. |
| `"Take note buy groceries after work"` | Adds groceries reminder to notes. |
| `"Read my notes"` | Reads back and displays all saved notes in the transcript feed. |
| `"Show all notes"` / `"What do you remember?"` | Displays all recorded notes. |
| `"Delete all notes"` | Clears and erases all notes from `data.txt`. |
| `"Clear my notes"` / `"Remove notes"` | Empties the notes file. |

## 5. Full Computer & Windows Hardware Control
Control your Windows operating system and desktop directly using voice or text.

| Example Voice / Text Command | Jarvis Action |
| :--- | :--- |
| `"Volume up"` / `"Increase volume"` / `"Louder"` | Raises Windows master system volume. |
| `"Volume down"` / `"Decrease volume"` / `"Lower volume"` | Lowers Windows master system volume. |
| `"Mute"` / `"Unmute"` / `"Mute sound"` | Toggles system sound mute. |
| `"Minimize Chrome"` / `"Minimize chorme"` | Minimizes **only** Google Chrome to the taskbar without touching other windows. |
| `"Close Chrome"` / `"Close chorme"` | Closes **only** Google Chrome. |
| `"Restore Chrome"` / `"Maximize Chrome"` | Restores Google Chrome back to the screen. |
| `"Minimize Notepad"` / `"Close Notepad"` | Minimizes or closes only Notepad. |
| `"Minimize Edge"` / `"Close Edge"` | Minimizes or closes only Microsoft Edge. |
| `"Minimize VS Code"` / `"Close VS Code"` | Minimizes or closes only Visual Studio Code. |
| `"Minimize all windows"` / `"Show desktop"` | Minimizes all active windows to show the desktop (`Win + D`). |
| `"Close window"` / `"Close this app"` | Closes the active foreground window (`Alt + F4`). |
| `"Switch window"` / `"Next app"` | Cycles through open applications (`Alt + Tab`). |
| `"Lock my computer"` / `"Lock screen"` / `"Lock PC"` | Instantly locks your Windows workstation. |
| `"Empty recycle bin"` / `"Clean trash"` | Permanently cleans out the Windows Recycle Bin. |
| `"Battery status"` / `"Check battery"` | Reports battery percentage or confirms direct AC desktop power. |

| :--- | :--- |

💡 **Pro Tips for the Best Experience**:
- **Voice or Text**: Every single command above works identically whether spoken through your microphone or typed into the text entry bar.
- **Click the Arc Reactor**: In the HUD GUI, clicking anywhere on the glowing blue Arc Reactor circle instantly arms the microphone for speech.
- **Quick Action Chips**: The bar just above the command prompt provides instant 1-click triggers for the most common commands (*Time, Date, Music, Notes, Screenshots, Volume, Wikipedia, Jokes*).
